# Account REST API Service

[![Build Status](https://github.com/siddhiparmeshwarshinde123-blip/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/siddhiparmeshwarshinde123-blip/devops-capstone-project/actions/workflows/ci-build.yaml)

## Project Overview

The Account REST API Service is a Python Flask application that provides RESTful endpoints to create, list, read, update, and delete account records.

## Technologies

- Python
- Flask
- REST API
- GitHub Actions
- Docker
- Kubernetes
- OpenShift Pipelines (Tekton)

## Features

- Create an account
- List all accounts
- Read an account
- Update an account
- Delete an account
- Automated testing and code linting
- Containerization and Kubernetes deployment
